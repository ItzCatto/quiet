Install

  1. Download the profile. If Safari asks, tap Allow.
  2. Open Settings and tap Profile Downloaded.
  3. Tap Install, enter your passcode, then tap Install again.
  • Check itSettings › General › VPN & Device Management lists Quiet DNS.
  • Change a settingSave and install again. There should still be one entry. If there are two, remove both, then install once.
  • PauseSwitch Quiet DNS off, save and install. Experimental, so check your DNS afterwards.
  • RemoveIn the same place, tap Quiet DNS, then Remove Profile. This always works.
