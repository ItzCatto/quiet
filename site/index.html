Install

Install the profile on your iPhone in four steps.

  1. Download the profile on the Profile screen. If Safari asks to download a configuration profile, tap Allow.
  2. Open Settings and tap Profile Downloaded near the top.
  3. Tap Install, enter your passcode, tap Install again, then tap Done.
  4. Check the result. Settings › General › VPN & Device Management should list Quiet DNS. Then load a page full of ads, or run a DNS test.

Not yet tested on an iPhone. Check the entry after each install.

Change a setting

Change the settings, download the profile again, and install it. The new profile replaces the Quiet DNS entry, so you should still see one entry afterwards. If you see two, remove both, then install once.

Pause, resume or remove

Pause
Turn Quiet DNS off, then download and install the paused profile. This is experimental. Check your DNS afterwards.
Resume
Turn Quiet DNS on, then download and install the profile again.
Remove
Open Settings › General › VPN & Device Management, tap Quiet DNS, then tap Remove Profile. This always works.

Privacy

What happens to your lookups, and what this website keeps.

  • This website builds your profile in your browser. It doesn't save your choices or send them anywhere.
  • AdGuard DNS sees the domain names your iPhone looks up. Read AdGuard's privacy policy before you rely on it.
  • While Quiet DNS is paused, your network's DNS sees those lookups again.
