Install

  1. Download the profile. If Safari asks, tap Allow.
  2. Open Settings and tap Profile Downloaded.
  3. Tap Install, enter your passcode, then tap Install again.
Check it
Settings, General, VPN & Device Management lists Quiet DNS.
Change a setting
Save and install again. There should still be one entry. If there are two, remove both, then install once.
Pause
Switch Quiet DNS off, save and install. Experimental, so check your DNS afterwards.
Remove
In the same place, tap Quiet DNS, then Remove Profile. This always works.

Privacy

  • Your network can't see the sites you look up, but AdGuard DNS can. Read its privacy policy first.
  • While Quiet DNS is paused, your network's DNS sees your lookups again.
  • The profile is built in your browser. This site has no accounts or analytics.
  • This site keeps your theme and last saved settings in this browser only.
